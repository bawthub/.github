# BawtHub

**A home for everything your bots do.** BawtHub brings conversations, voice, memory, creative tools, and agent development into one self-hosted workspace. Chat from any screen, give agents work to own, and see what actually happened instead of waiting on a spinner.

### What we're building

- **Conversations with continuity.** Named bots, searchable history, semantic memory, and switchable models and personas.
- **Agent work you can inspect.** Live tool calls and results, tasks, handoffs, changed files, and reviewable work trails.
- **More than a coding interface.** Voice, media, and everyday tools share the same home as the development cockpit.
- **A model-agnostic foundation.** Cloud and local models, plus agent runtimes, connect through `llm-bawt`'s OpenAI-compatible API.

### Explore

- [See BawtHub in action](https://bawthub.com) — the product tour, real UI captures, and system architecture.
- [Explore llm-bawt](https://github.com/bawthub/llm-bawt) — the open-source backend for bot routing, memory, tools, and agent bridges.

BawtHub is an independent project under active development. The `llm-bawt` backend is open source; the BawtHub frontend and hosted instance are private.
